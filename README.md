二、程式用途

本程式用來整理「桌遊體驗」與「電影欣賞」兩場活動的報名資料。

程式會先清理姓名中的半形空白，並將英文統一轉換成小寫，再使用 list 保存整理後的資料，使用 set 去除重複姓名並比較兩場活動的參加者。

最後使用 dict 保存人數及費用摘要，計算各場活動應收金額與總應收金額。

三、使用的資料型別
資料型別	使用用途
str	保存原始報名文字
tuple	保存兩個活動名稱
list	保存整理後的報名名單
set	去除重複姓名，計算交集、聯集及差集
dict	保存活動費用及計算摘要

五、個人問題回答
問題一

測試一中，整理後的桌遊串列有 4 筆資料，為什麼桌遊費用應以 3 人計算？直接把字串拆成 list，和再轉成 set，各自保留了什麼、失去了什麼？

我的回答：

list 會保留所有整理後的報名資料，因此 amy 重複出現兩次，總共有四筆資料。

轉換成 set 後，重複的 amy 會被去除，只剩下 amy、ben、cora 三個人，因此收費應以三人計算。

list 保留原本的順序及重複資料；set 會去除重複資料，但不保留原本的順序。因此可以先用 list 保存完整報名資料，再使用 set 進行去重及人數計算。

問題二

測試三中，兩場活動只有 3 位不同的人，為什麼是 6 人次、總應收仍是 600 元？請用集合關係與算式說明。

我的回答：

測試三中，桌遊與電影的集合完全相同，交集有三個人，聯集也只有三個人。

但是每個人都參加兩場活動，所以桌遊有三人次，電影也有三人次，合計六人次。

桌遊費用為 3 × 120 = 360 元，電影費用為 3 × 80 = 240 元，因此總應收為 600 元。
